# Decisions

Newest first. Status: *done* (in code), *approved* (agreed, not in code yet), *planned*.

| Date | Decision | Why | Status |
|---|---|---|---|
| 2026-11-13 | Cleanup of the inherited ST AT layer: removed the unused / duplicate commands (`AT+NWKSKEY`, `AT+APPSKEY`, `AT+DADDR`, `AT+NWKID`, `AT+LINKC`, `AT+PGSLOT`, `AT+RX2DR`, `AT+RX2FQ`, `AT+TTH`, `AT+TOFF`, `AT+REGW`, `AT+REGR`) and unused functions; `live_config` replaced by `EepromVars_t eeprom_vars` (only the EEPROM part has a RAM copy; the stack holds the NVM values). **Exception to the CubeMX rule:** `lora_at.c`, `lora_command.c`, `lora_at.h` were edited outside USER CODE, approved by the project owner because there is no `.ioc` file and CubeMX cannot regenerate them. Identity is set only with `AT+KEY` / `AT+ID` | Smaller AT surface, one way to set identity, less dead code | done (working copy, not committed, not tested on hardware) |
| 2026-11-12 | The device identity is no longer in the firmware (`device_vars` and `init_pre_join()` removed): keys and DevAddr come from the NVM context, set by the host (`AT+ID`, `AT+KEY`); region is the compile-time `ACTIVE_REGION`. Boot never writes EEPROM; the new `AT+PROFILE=<n>` (`profile_set()`) stores a profile and resets, `init_phase` gets `INIT_PHASE_NONE` (not configured; modules from older firmware must receive `AT+PROFILE` once). The key / DevAddr setters `lw_*_set()` store the NVM context at once | No secrets in the firmware; one flow for a new module and for a profile switch; no EEPROM wear at boot | done (working copy, not committed, not tested on hardware) |
| 2026-11-10 | Configuration profiles: `const` profiles in firmware (EEPROM part + NVM part), one live struct (`live_config`) replacing `eeprom_vars` / `ram_vars` (since 2026-11-13 only `eeprom_vars` of the EE part remains); `init_phase` kept (0 / 1 / 2), profile ID the modem is configured with in EEPROM VA 15, hash of the profile in VA 16 (function to be decided) ([vision.md](vision.md)) | Reproducible configuration, host can switch profiles, firmware updates can change a profile; AT overrides survive reboots | done (working copy, not committed, not tested on hardware) except the hash: planned |
| 2026-11-10 | Device identity (keys, DevAddr) outside profiles | Switching profiles keeps identity and FCnt, no ABP deactivation | done (working copy, not committed); since 2026-11-12 not in the firmware at all |
| 2026-11-10 | Profile layer is a thin layer on `lw_*` / `dev_*`, no change to ST middleware; also sets stack defaults (e.g. TX power / antenna gain as `lw_power_set()`); `lowpower_auto` moves to EEPROM VA 14; `lowpower_once` stays RAM (`dev_state`) | Keep the middleware upgradable | done (working copy, not committed) |
| 2026-11-10 | `init_pre_join()` / `init_post_join()` moved from `main.c` to `auto_init.c`, kept as `auto_init_run()` (since 2026-11-12 without `init_pre_join()`); the first version with `auto_init_apply()`, `restore_stack()` and markers was dropped as too complicated | Prepare and implement the profiles | done (working copy, not committed) |
| 2026-11-09 | Documentation in `docs/` maintained by a Librarian agent; `context.md` is a short stable brief | Keep agent context small; one owner keeps docs consistent with the code | done |
| 2026-11-09 | Move the Doxygen output to `docs/api/` when the git repo moves to the project root | One documentation location | planned |
| 2026-11-09 | Derive the mode from the stack (`lw_mode_get()` = `LoRaMacIsStopped()`, MAC started at boot) instead of `ram_vars.mode` | The flag only holds the last set value, it does not track the stack | done (working copy, not committed) |
| – | Boot autoconfiguration controlled by `init_phase` and the profile ID in EEPROM ([boot.md](boot.md)) | Modem configures itself once; later boots only restore | done (working copy, not committed); hash open |
| – | AT layer only parses and prints; functionality in the `lw_*` / `dev_*` C API (commit `92862ad`, `a7c0de1`) | Use features without AT commands; fewer AT commands at host init | done |
| – | EU868 and ABP only | Target network; reduces scope | done |
| – | Seeed emulation: no boot banner, trace level OFF after reset | Unsolicited lines after a reset break the ESP driver | done |
